## About us

We're a small group of infrastructure and AI engineers, working in IaC, GitOps, DevOps, SRE, and AI. We build four tools, and we use all of them every day.

## Our tools

### <img src="https://opspresso.com/images/toast.png" width="26" align="top"> [Toast](https://toastapp.dev) <sub>macOS · Windows</sub>

**A launcher you summon with one shortcut.**

A global hotkey opens your own pages of buttons. Run commands, open files and URLs, execute scripts, chain actions, or launch applications — and keep the whole setup in step across devices.

<sub>Custom button pages · Text snippets · Light &amp; dark themes · Cloud sync</sub>

### <img src="https://opspresso.com/images/vibemon.png" width="26" align="top"> [VibeMon](https://vibemon.io) <sub>Claude Code · Codex · Kiro · OpenClaw</sub>

**See what your coding agent is doing without asking it.**

A pixel art character in the system tray shows at a glance whether the agent is thinking, working, or waiting for you — along with the active project, tool, model, and context usage.

<sub>System tray status · Context usage · Hook-based, no wrapper · ESP32 display</sub>

### <img src="https://opspresso.com/images/agent-studio.png" width="26" align="top"> [Agent Studio](https://studio.opspresso.com) <sub>Console · OpenAI-compatible API · Slack</sub>

**Build production AI agents, then actually run them.**

Author prompts and agents as versioned projects, then serve them through the console, an API, Slack, or webhooks. The agent loop handles multi-turn tool use with turn budgets, on-demand skills, and subagent transfers.

<sub>MCP tools · Live traces · Evaluation · Per-call cost limits</sub>

### <img src="https://opspresso.com/images/romty.png" width="26" align="top"> [romty](https://romty.dev) <sub>macOS · Linux</sub>

**Close the terminal. The shells keep running.**

A detached daemon owns the shell PTYs, so closing the window leaves every process alive. Reopen it and romty reattaches and replays what you missed, with your projects and their tabs where you left them.

<sub>Detached sessions · Project tabs · 10,000-line scrollback · IME-independent keys</sub>
